# Ray-Flow

**Ray-Flow** is an interactive physics project that allows users to experiment with light rays and explore basic concepts of optics through a visual environment.

Originally developed as a school project for Physics, Ray-Flow aims to make learning about light more interactive and intuitive.

## About the Project

The project provides a visual playground where users can interact with light rays and explore how light behaves.

Rather than relying only on theoretical explanations, Ray-Flow offers a hands-on approach to understanding physics concepts.

## Built With

- **Unity** – Game engine
- **C#** – Programming language

## Getting Started

To run the project locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/alexgdin/Ray-Flow.git
   ```

2. Open **Unity Hub**.
3. Select **Add Project from Disk**.
4. Choose the cloned `Ray-Flow` folder.
5. Open the project using a compatible Unity version.
